# Security policy

## Supported versions

The latest commit on `main` is supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue containing exploit details, secrets, or personal data.

## Data policy

This repository accepts synthetic fixtures only. Do not submit customer data, resident information, property addresses, source workbooks, credentials, production identifiers, or private deployment configuration in issues, pull requests, discussions, logs, or test artifacts.
